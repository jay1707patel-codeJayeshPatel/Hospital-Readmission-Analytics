# Hospital Readmission Analytics

A Healthcare Analytics project built using Python to analyze hospital readmission patterns through data cleaning, exploratory data analysis (EDA), statistical testing, and machine learning models.

## Project Overview

Hospital readmissions are a major challenge for healthcare systems. This project identifies factors associated with patient readmission by performing:

- Data Cleaning
- Exploratory Data Analysis
- Statistical Testing
- Linear Regression
- Logistic Regression
- Healthcare Interpretation

## Tools Used

## Healthcare Insights

The analysis indicates that:

- High-risk patients tend to experience longer hospital stays.
- Certain diagnoses show higher readmission frequencies.
- Patient demographics and clinical risk influence readmission probability.
